# Expense Tracker

A local-first web app for keeping track of expenses and exporting a PDF report of it

## Requirements

- Python 3
- [Flask](https://flask.palletsprojects.com/en/stable/)
- [ReportLab](https://docs.reportlab.com/reportlab/userguide/ch1_intro/)

## Getting started

Install the Python dependencies

   ```bash
   python3 -m pip install Flask reportlab
   ```

Then start the app

   ```bash
   python3 app.py
   ```
